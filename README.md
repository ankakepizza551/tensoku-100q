# 東方非想天則 天則勢100の質問

東方非想天則プレイヤー向けの100問アンケートフォームです。

## 機能

- 100問への回答（自動保存）
- キャラ名の入力補完・表記ゆれの自動補正
- 未回答の質問へのジャンプ、セクション単位のリセット
- 回答データのバックアップ保存・復元（`.json`）
- テキストのコピー・`.txt`ファイル保存
- セクション別の画像保存（X投稿用・4枚構成、まとめて保存可）
- Xの投稿画面を開くボタン

## 使い方

[GitHub Pages で公開中](https://ankakepizza551.github.io/tensoku-100q/)

## ローカルで動かす場合

```bash
npm install
npm run dev
```
